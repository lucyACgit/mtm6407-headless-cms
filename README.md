# mtm6407-headless-cms

## Type of review site

**Movie reviews.** The site reviews 10 of the most watched movies of 2026, based on a Letterboxd list ranked by number of views. Each review has a title, a 1–5 star rating and a short written review.

## Headless CMS: Strapi 5

- The reviews are created and published in the Strapi admin panel.

## Frontend tool: VitePress (Vue)

- VitePress 1.6 with the default theme and a small custom stylesheet.
